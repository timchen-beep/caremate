# CareMate 演示脚本（8 分钟，照着念也能演完）

> 对应《实现步骤目标》第 10 步：换个生人照纸条也能演完。
> 前置：`cd F:\ppt\caremate-cloud && start.bat`，浏览器开 `http://127.0.0.1:8000/`。
> 全程只用两个标签页：`/app`（老人）、`/dashboard`（家属）。

## 0. 开场 30 秒

"这是给独居老人用的提醒助手。老人端只有三件事：看提醒、点确认、按呼救；家属端是网页，负责建提醒、看进度、收告警。"
（指着两个标签页，不要打开代码）

## 1. 建提醒：家属建、老人收（2 分钟）

1. 家属页 → **提醒计划** → 名称填"缬沙坦 80mg"，时刻填 **当前时间 +2 分钟**，规则"每天" → 新增。
   > 说：这条计划是家属建的，老人手机不需要操作。
2. 老人页 → **刷新** → "今天的计划"里出现这条，状态"待提醒"。
3. 等到点（或直接说"已经过点了"）→ 老人页顶部出现大红卡片 + 语音播报。
4. 点 **"吃了，记一下"** → 卡片消失，底下出现 **5 秒撤销条**。
   > 说：怕点错，5 秒内能撤。点一下撤销条 → 回到"待提醒"；再点一次确认。
5. 看家属页 → 该实例变 **已完成**，并显示确认时间。

## 2. 不改历史（1 分钟）

1. 家属页把这条计划的时刻改成 2 小时后 → 保存。
2. 回到今日实例：**刚才那条仍然是老时间、老状态**，只有新的那条按新时刻生成。
   > 说：改计划不许篡改已经发生的事。

## 3. 没确认会自己升级（1 分钟）

1. 再建一条计划，时刻设 **3 分钟前**。
2. 老人页刷新 → 状态"未确认"。
3. 家属页 → **告警** → 看到"未确认升级清单"，级别 L2/L3，带"通知 20:11"。
   > 说：没人管不会烂在那儿，到点提醒 → 2 分钟推给家属 → 15 分钟记未确认。

## 4. 呼救（30 秒）

1. 老人页右上角红色 **按住呼救** → 按住 3 秒（进度条走满）。
2. 家属页 → **告警** 出现 level 3 的 `sos`。
   > 说：长按 3 秒才触发，防误触；家属和社区同时收到。

## 5. 记录能改能撤（1 分钟）

1. 老人页 → **记录** → 点"喝水 200ml"。
2. 家属页 → **记录** → 找到这条 → **撤销** → 列表里消失，历史里留痕（谁、什么时候、哪条）。
   > 说：记错了 30 分钟内能撤，撤了有痕迹，不是抹掉。

## 6. 可靠性三连（2 分钟，可选但最有说服力）

- **重启**：关掉 `start.bat` 再开 → 刷新老人页，未完成的提醒仍在，没有多出来的。
- **重复提交**：点确认后立刻再点（或让家属代确认）→ 家属页仍只有 1 条记录。
- **改时间**：把电脑时间调快 1 小时 → 刷新 → 不出现重复提醒，倒计时不为负；调回。

## 7. 收尾 30 秒

"这一版做了 1、3、4、5、6 步；2 的锁屏提醒要 APK，7 的 kiosk 要设备权限，8、9 是硬件和加分项——这几条我们没做，也不假装做了。"
（主页 `/` 有全部入口；`README.md` 有验收命令）

## 出问题时的兜底

| 现象 | 处理 |
|---|---|
| 页面 404 / 空 | 服务没起：双击 `start.bat`，等窗口出现"已启动" |
| `Failed to fetch` | 端口被占：`server.py --port 8001`，老人页"我的"里改服务器地址 |
| 时间对不上 | 服务器与电脑时区不同：`set CAREMATE_TZ=Asia/Shanghai` 再启动 |
| 撤销失败 409 | 超过 5 秒，说明这是设计如此；重演一次即可 |

## 附：本轮新增的四个可演点

**第 1 步 · 七天排程对一遍**（不需要等时间）

```bat
python server.py --preview 7
```

打印未来 7 天每天几点提醒，七种规则各建一条后当场和纸对。网页也能看：`/api/v1/preview?elder_id=u-elder&days=7`。

**第 2 步 · 十分钟演示阈值**

```bat
python server.py --port 8000 --demo
```

升级阈值变 1/3/10 分钟、等会儿 5 分钟，和《实现步骤目标》第 2 步的"过十分钟自己记未确认"对齐。**验收脚本仍用默认 2/15，别混用。**

**第 6 步 · 真的发一条通知**

```bat
python server.py --notify-test https://你的webhook地址
```

成功打印 `{'sent': True, ...}`；没配 `CAREMATE_WEBHOOK_URL` 时接口会返回 409 并说明原因，不会假装发出去。

**第 7 步 · 专注模式（网页近似）**

打开 `/kiosk`：四个大按钮（吃药 / 记一笔 / 找家人 / 按住呼救），装成 PWA 后无地址栏；
左上角**按住 5 秒**退出。真正的锁 Home/返回要靠 Android 设备管理，这一版只做到"网页退不出去、但退得回来"。
