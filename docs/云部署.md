# 上云部署（约 40 分钟）

## 0. 规格

- 2 核 2 G / Ubuntu 22.04，安全组放行 22 / 80 / 443
- 域名（HTTPS 必需）：A 记录指向服务器 IP

## 1. 上传与安装

```bash
scp -r server root@IP:/opt/caremate
ssh root@IP
apt update && apt install -y python3 tzdata curl rsync
```

## 2. 先换掉演示令牌（必做）

编辑 `/opt/caremate/server.py` 里 `init_db()` 的三个 `token` 与 `bind_code`，改成长随机串。
不改就挂公网 = 任何人拿 `fam-demo-2026` 都能看数据。

## 3. systemd（单进程）

```bash
cp /opt/caremate/deploy/caremate.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now caremate
journalctl -u caremate -f     # 看到「调度器 开」
```

## 4. Caddy 自动 HTTPS

```bash
apt install -y caddy
sed 's/caremate.example.com/你的域名/' /opt/caremate/deploy/Caddyfile > /etc/caddy/Caddyfile
systemctl reload caddy
```

## 5. 验证

```bash
curl -s https://你的域名/api/v1/health
curl -s -H "X-Token: 家属令牌" https://你的域名/api/v1/metrics
```

手机 4G 打开 `https://你的域名/app`，改服务器地址与令牌，确认一次 → 看板出现。

## 6. 备份

```bash
echo '0 3 * * * cd /opt/caremate && python3 server.py --backup >> /var/log/caremate-backup.log 2>&1' | crontab -
```

再把备份拉回本地，别只留在云上。

## 边界

单机无高可用；服务器重启/欠费 = 提醒停摆。不要承诺 7×24。
