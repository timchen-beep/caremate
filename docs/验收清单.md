## B. 树莓派 / 香橙派（需要板子）

```bash
bash pi/setup-pi.sh
mosquitto_sub -h 127.0.0.1 -t 'home/#' -v     # 一个窗口挂着
curl -X POST http://127.0.0.1:8000/api/v1/sos -H "X-Token: app-elder-001" -d '{}'   # 另一个窗口
```
期望：订阅窗口立刻出现 `home/alarm/u-elder {"kind":"sos",...}`。

## C. ESP32（需要硬件）

1. 烧 `esp32/esp32_node.ino`，串口看到 `[mqtt] 已连上并订阅`
2. 手在雷达前动：串口 `[radar] 有人`，同时订阅窗口有 `home/sensor/presence`
3. 触发呼救：ESP32 红灯 + 长鸣

## D. root 安卓（需要演示机）

```bash
bash android-root/00-precheck.sh          # 先确认设备与 root
bash android-root/10-grant-exact-alarm.sh # 精确闹钟 + 白名单
bash android-root/30-kiosk.sh on          # 锁成"只有这一个 App"
bash android-root/30-kiosk.sh off         # 一定要演一遍恢复
bash android-root/40-chaos.sh reboot      # 四种异常：offline/reboot/time-skew/tap-spam
```

## E. Qt 端（需要 Qt 6.5+ 与 Android Kit）

```bash
cd app-qt
qt-cmake -S . -B build -DQT_HOST_PATH=<host qt>
cmake --build build
```
先跑桌面版看布局（`./build/appCareMate`），再 `--target apk` 出安装包。

> 桌面版能跑通只代表 QML 没错；**精确闹钟必须在真机上验**（JNI 那层在桌面是模拟的）。
