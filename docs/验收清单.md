## 二、App（需要安卓手机）

- [ ] 装 APK，改「我的」里的服务器地址为电脑局域网 IP
- [ ] 点确认 → 看板 10 秒内变"已完成"
- [ ] 锁屏扣桌上，2 分钟后自己亮屏响铃
- [ ] 飞行模式下点确认 → 关飞行 → 看板正好多 1 条
- [ ] 长按呼救 3 秒 → 看板弹红条

## 三、硬件（可选）

见 `docs/硬件接入.md`：树莓派起 broker → ESP32 烧固件 → 手在雷达前晃 → 灯变色。

雷达数据要进服务端，还得同时跑桥：`python bridge.py --host <broker> --token <老人令牌>`——它订阅 `home/sensor/presence` 并转成 `POST /api/v1/sensor/presence`，不跑这一环，久未活动告警拿不到输入（详见 `docs/硬件接入.md`）。
