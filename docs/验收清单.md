## 二、App（需要安卓手机）

- [ ] 装 APK，改「我的」里的服务器地址为电脑局域网 IP
- [ ] 点确认 → 看板 10 秒内变"已完成"
- [ ] 锁屏扣桌上，2 分钟后自己亮屏响铃
- [ ] 飞行模式下点确认 → 关飞行 → 看板正好多 1 条
- [ ] 长按呼救 3 秒 → 看板弹红条
