用配对码换令牌 文档 4.2.7：不发账号密码

换到的令牌只绑这一个老人，30 天有效；换手机或清了缓存就重新配一次。 当前页面右上角的令牌框会自动换成新令牌（也可以手动粘贴）。

事件出口（outbox）

topic 约定
home/reminder/{user}/state、home/record/{user}、home/alarm/{user}、home/sensor/presence、home/terminal/ack
本地模式
写 SQLite outbox 表，桥进程拉取后转发 MQTT
云模式
把 publish() 换成 paho-mqtt publish 或 Webhook POST，调用方不用改

上云清单

1. 数据库：CAREMATE_DB 换 PostgreSQL 连接串（本文件 connect() 是唯一切换点）；
2. 鉴权：CAREMATE_JWT_SECRET 非空后改为签发/校验 JWT（当前固定令牌，便于演示）；
3. 事件出口：CAREMATE_MQTT_URL=mqtt://127.0.0.1:1883，publish() 内改为真实发布；
4. 社区上报：CAREMATE_WEBHOOK_URL 指向社区后台；
5. 成本口径（文档 R7-5）：1 核 2G 学生机 50–100 元/月，演示场景零成本。
