# 签名与升级

| 项 | 值 |
|---|---|
| 包名 | `com.caremate.caremate` |
| 证书 | `CN=CareMate, OU=Project, O=CareMate, L=Shanghai, ST=Shanghai, C=CN` |
| 证书 SHA-256 | `5a200ea87262ceac00d6bd074474a6dea6a1aba187fc027921ba771febf8d5d5` |
| 签名方案 | v1 + v2 |
| 密钥库 | 构建机 `caremate_app/android/caremate-release.jks`（**不要丢**） |

## 升级规则

- 同一包名 + 同一签名才能覆盖升级；换了证书必须卸载重装（数据丢失）。
- 装成 priv-app 后，升级有两种方式：
  1. 替换 `/system/priv-app/CareMate/CareMate.apk` 后重启（需要 root）
  2. `adb install -r` 装到 /data，**优先于**系统版本（系统版本仍在，但被覆盖）——演示更省事

## 演示机建议

- 关掉 Play 商店自动更新，避免演示前被系统改版本
- 备份一份 `CareMate-release.apk` 到 U 盘，现场重装用
