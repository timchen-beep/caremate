# 服务端页面

| 文件 | 给谁用 | 关键函数 |
|---|---|---|
| `dashboard.html` | 家属（电脑浏览器） | `refresh()` 每 5 秒增量刷新、`watchAlarms()` 长轮询告警、`incoming()` 弹红条、`renderCloud()` 云端分区、`renderRecords()`/`renderPlans()` 表格 |
| `app.html` | 老人（网页/PWA 预览版） | `act()` 提交动作、`queuePush()`/`flushQueue()` 断网补记、`speak()` 语音、`runCheck()` 无障碍自检 |
| `kiosk.html` | 老人（专注模式全屏） | `tick()` 刷新、`fire()` 呼救/退出（失败会明确说"没发出去"，不假装成功） |
| `index.html` | 所有人 | 落地页与三个入口（不再在页面上明文列令牌） |
| `manifest.webmanifest` / `sw.js` | 浏览器 | PWA 清单与 Service Worker：缓存静态页，离线可打开 |

这些页面**不含业务逻辑**：只负责显示与把点击转成一次接口调用。状态全在 `server.py`。

## 令牌从哪来（页面一个都不写死）

- 家属看板：右上角「令牌」框填家属令牌，或直接开一次性链接 `/dashboard?token=<家属令牌>`；
- 老人端：底部「我的」→「设备令牌」，或 `/app?token=<老人令牌>&base=<服务器地址>`；
- 大屏 kiosk：没有输入框，读 `/app` 存下的同一个令牌，所以先配 `/app`；
- 配对：看板「用配对码换令牌」，输 6 位配对码换一个 30 天的会话令牌（`ses-…`）。

交接链接的做法是**先写 localStorage 再把 token 从地址栏抹掉**（`handoffToken()`），
令牌 24~32 位手抄必错，留在地址栏又会进浏览器历史、代理日志和截图。

## 三个常见误判（都改过）

1. 令牌失效时页面显示「离线」并清空旧数据（`clearAll()`），不会拿上一位老人的数据冒充最新；
2. 断网时老人端点「已确认」会进本地队列、联网自动补发，`event_id` 保证不重复记；
3. 社区上报的告警内容在渲染前一律 `esc()`，`<img onerror>` 这类载荷不会在别人会话里执行。
